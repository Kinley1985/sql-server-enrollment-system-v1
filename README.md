# SQL Server Enrollment System

A hands-on SQL Server project for learning relational database design, SQL fundamentals, and Data Engineering concepts.

## Project Overview 

This project is designed to practice SQL Server fundamentals through an Enrollment System database.

## Learning Objectives

- Learn Data Definition Language (DDL)
- Learn Data Manipulation Language (DML)
- Learn Data Query Language (DQL)
- Understand Primary Keys and Foreign Keys
- Practice SQL Server database design
- Build a strong SQL foundation for Data Engineering

## My Learning Journey

This project is more than just a SQL practice repository.

I started by watching tutorials, following lessons, and practicing every concept step by step. Instead of stopping after completing the tutorials, I decided to build this project to strengthen my SQL skills and continue my journey toward becoming a Data Engineer.

I know that every project comes with mistakes, and I believe that every mistake is an opportunity to learn and improve.

I believe that age and time should never be barriers to learning. As long as we continue practicing and building projects, we continue growing.

I also hope this repository can help other self-taught learners who are beginning their SQL journey.
